### 前言
大家好，我是路明。今天，我们一起来用C++来解决一个数学问题。
### 问题
问题如下：

<img class="aligncenter" src="https://luming-website.chgskj.cn/luming-notes/2024/01/20240130082746169560.webp" />
### 初步解决
由题可知，题目要求用户输入圆的半径至程序，接下来在程序内部进行运算，最后输出圆的直径、周长和面积。

根据圆的计算公式，可知：
<pre class="corepress-code-pre"><code>d=2r
c=πd=2πr
s=πr²d</code></pre>
有了这些公式，解决这个问题也就易如反掌了。

&nbsp;
### 代码编写
在本程序中，需要用到C++中<code>iostream</code> 、<code>iomanip</code> 、<code>cstdio</code> 等头文件，因此我们在程序头部输入以下代码：
<pre class="corepress-code-pre"><code>#include&lt;iostream&gt;
#include&lt;iomanip&gt;
#include&lt;cstdio&gt;
using namespace std;</code></pre>
接着定义主函数【 int main() 】（代码略）。

&nbsp;

由于圆周率π约等于3.1415926，因此我们定义一个浮点型常量PI，值为3.1415926，方便我们以后使用：
<pre class="corepress-code-pre"><code>const float PI=3.1415926;</code></pre>
[c-alert type="success"] 输入完命令代码后，可别忘了加上“；”噢～[/c-alert]

&nbsp;

继续，为了方便程序进行内部计算，我们定义几个浮点型变量，用来存储圆的半径、直径、周长和面积的值：
<pre class="corepress-code-pre"><code>float banjing,zhijing,zhouchang,mianji;</code></pre>
好了！对变量的定义部分到此就结束了，接下来，我们要往变量里填东西了。我们先让用户输入圆的半径：

&nbsp;
<pre class="corepress-code-pre"><code>cin&gt;&gt;banjing;
</code></pre>
接着就可以在程序内对圆的直径、周长和面积进行计算了。
<pre class="corepress-code-pre"><code>zhijing=banjing*2;//直径=半径*2
zhouchang=2*PI*banjing;//C=2PIr
mianji=PI*banjing*banjing;</code></pre>
最后，根据题目要求，我们需要将直径、周长和面积保留四位小数后输出，并在结果之间添加空格。

这里我们可以用两种方式来实现该效果。首先使用iostream头文件中包含的<code>cout&lt;&lt;</code> 命令
<pre class="corepress-code-pre"><code>cout&lt;&lt;fixed&lt;&lt;setprecision(4)&lt;&lt;zhijing&lt;&lt;" "&lt;&lt;zhouchang&lt;&lt;" "&lt;&lt;mianji;</code></pre>
其中<code>cout&lt;&lt;fixed&lt;&lt;setprecision(4)</code>  代表保留结果为4位小数，<code>zhijing&lt;&lt;" "&lt;&lt;zhouchang&lt;&lt;" "&lt;&lt;mianji;</code> 即为按格式输出结果。

第二种方法是用cstdio中的<code>printf()</code> 命令：
<pre class="corepress-code-pre"><code>printf("%.4f %.4f %.4f %.4f",banjing,zhijing,zhouchang,mianji);//输出格式为保留四位小数的浮点数</code></pre>
printf()命令的参数是用“，”分隔开的。其中第一个参数代表着输出内容的格式，从第二个开始，即为输出的内容。

<code>"%0.4f %0.4f %0.4f"</code> 中的每个“%0.4f”都分别代表着zhijing、zhouchang、mianji的输出格式，又因为输出的结果之间有空格，所以在此参数中的每个%0.4f之间都有一个空格。

%0.4f的意思是保留四位小数后输出。

在程序的末尾，请一定不要忘记编写<code>return 0;</code> ！

### 源代码
<pre class="corepress-code-pre"><code>#include &lt;iostream&gt;
#include&lt;iomanip&gt;
#include&lt;cstdio&gt;

using namespace std;
int main() 
{
	const float PI=3.14;
	float banjing,zhijing,zhouchang,mianji;
	cin&gt;&gt;banjing;
	zhijing=banjing*2;
	zhouchang=2*PI*banjing;
	mianji=PI*banjing*banjing;
	printf("%0.4f %0.4f %0.4f",zhijing,zhouchang,mianji);
	//cout&lt;&lt;fixed&lt;&lt;setprecision(4)&lt;&lt;zhijing&lt;&lt;" "&lt;&lt;zhouchang&lt;&lt;" "&lt;&lt;mianji;

}</code></pre>
